# TRACK – Einrichtung (ca. 10 Minuten)

TRACK nutzt dieselbe Supabase-Datenbank wie Finance, aber mit eigenem Login.
Die Daten sind in der App vollständig getrennt.

## Teil Thierry (am Mac)
1. **GitHub:** + → New repository → Name `track`, Public → Create
2. «uploading an existing file» → den *Inhalt* dieses Ordners hineinziehen (inkl. `icons`, `vendor`) → Commit changes
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
   → Adresse: `https://thierryroe.github.io/track/`
4. **Supabase:** Authentication → Users → Add user → Create new user
   - E-Mail und Passwort der neuen Nutzerin (sie tippt ihr Passwort am besten selbst ein)
   - Häkchen «Auto Confirm User» → Create user

## Teil Nutzerin (iPhone)
1. Adresse in **Safari** öffnen → Teilen → **Zum Home-Bildschirm** → «TRACK»
2. TRACK öffnen → Regler-Symbol → **Sync & Sicherheit**
   - Projekt-URL und Key: dieselben wie bei Finance
   - Eigene E-Mail und eigenes Passwort → **Anmelden**
3. Optional: **Mit Face ID sperren** einschalten
4. Einstellungen → **Monatsbudget** festlegen
5. Vermögen → Verwalten → Konten und Institute anpassen
